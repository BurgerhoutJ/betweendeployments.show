# Between Deployments

A conversation series about modern workplace IT — Intune, Entra ID, Windows 365, and everything that comes with managing devices in a cloud-native world. No fixed schedule, no filler: just honest conversations with people in the field, recorded whenever there's something worth talking about.

Hosted by **Jeroen Burgerhout** (Microsoft MVP).

🌐 [betweendeployments.show](https://betweendeployments.show)  
🎧 [Subscribe via RSS](https://api.substack.com/feed/podcast/2886741.rss)  
📰 [Substack](https://www.burgerhout.org/podcast)

## How it works

This site is built with [Jekyll](https://jekyllrb.com/) using the [Mediumish](https://github.com/codebygina/mediumish-theme-jekyll) theme, hosted on GitHub Pages.

A GitHub Action runs every 6 hours to fetch the podcast RSS feed from Substack and generate Jekyll posts automatically.

## Local development

```bash
bundle install
bundle exec jekyll serve
```
